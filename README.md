# Delight Cakes & Pastries

Static site: `index.html`, `style.css`, `main.js`, `assets/` (hero video, poster, cake photos) and `fonts/`.

- Hero: clear full-screen video background (`assets/hero.mp4`), nothing laid over it. On screens wider than 16:9 the whole video is shown so the cake is never cropped.
- Cakes: edit name, text, price and photo in `index.html` (search for `class="clay cake`). Photos are `assets/cakes/cake-1..4.webp` (2:3 portrait).
- Orders: WhatsApp number is set at the top of `main.js` (`WHATSAPP`) and in the footer/links in `index.html`.
- Palette: pink, white, grey and black only (see `:root` in `style.css`).
